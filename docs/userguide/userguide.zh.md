# 使用指南

**[English](userguide.en.md)** | [中文](userguide.zh.md)

这个模板交付的是一个能跑的桌面应用，所以本指南描述的是真实行为，不是设想中的产品。
哪些地方是留给你替换的占位功能，文中标明，见
[哪些是占位功能](#哪些是占位功能)。

## 开始使用

- 应用启动一个主窗口（1200×800，最小 1000×700），居中显示。
- 窗口尺寸与位置在下次启动时恢复。
- 再次启动不会开出第二个窗口，而是把已有窗口显示并聚焦。
- 应用注册了 `tauri-app://` 协议，因此从外部访问 `tauri-app://preferences` 或
  `tauri-app://command-palette` 就能打开对应界面。

## 键盘快捷键

下面是代码里真实存在的绑定：

| 操作                           | macOS       | Windows / Linux      | 绑定位置                       |
| ------------------------------ | ----------- | -------------------- | ------------------------------ |
| 命令面板                       | ⌘K          | Ctrl+K               | 应用内键盘监听                 |
| 偏好设置                       | ⌘,          | Ctrl+,               | 监听 + 原生菜单                |
| 切换左侧栏                     | ⌘1          | Ctrl+1               | 监听 + View 菜单               |
| 切换右侧栏                     | ⌘2          | Ctrl+2               | 监听 + View 菜单               |
| 切换侧边栏（偏好设置打开期间） | ⌘B          | Ctrl+B               | 设置对话框内置布局             |
| Quick Pane                     | ⌘⇧.（默认） | Ctrl+Shift+.（默认） | **系统级**，应用在后台时也有效 |
| Quick Pane 关闭                | Esc         | Esc                  | 面板内部                       |

两点要先说清楚，免得你按界面文案推断行为：

- 命令面板里窗口命令旁边显示的 `⌘W`、`⌘M`、`F11` 只是展示字符串，没有任何按键处理
  程序绑定它们。命令本身在面板里点选是有效的。
- 应用内监听只看 `⌘`/`Ctrl` 加一个键，没有排除 `Shift`，所以 `⌘⇧K` 同样会打开命令
  面板。

## 关窗口不等于退出

点窗口关闭按钮会把应用收进系统托盘，进程继续运行，Quick Pane 的全局快捷键也仍然
有效。

- 左键单击托盘图标切换窗口显隐；双击强制显示。
- 右键打开托盘菜单：**Show/Hide**、分隔线、**Quit**。
- 真正退出：托盘 **Quit**、应用菜单 **Quit**，或 macOS 的 ⌘Q。退出时会注销全局快捷键
  并隐藏 Quick Pane。
- macOS 上点 Dock 图标会把隐藏的主窗口带回前台。
- 这个行为没有设置项可改。托盘菜单文案与 tooltip 目前只有英文——Rust 侧尚未接 i18n。

## Quick Pane

一个 500×72 的输入条，出现在你光标所在显示器的居中位置，用系统级快捷键唤起，应用在
后台时也能弹出。

- 输入后按回车提交。主窗口会记录它，在内容区显示 `Last entry: <文本>`。
- 空内容或纯空白提交不会发送任何事件，但面板照样收起。
- Esc 或点击别处都会关闭。Esc 被吞掉，避免 macOS 发出"咚"的提示音。
- macOS 上它是真正的浮动面板：盖在全屏应用之上、点击不激活主应用、在所有 Space 都
  可见。其他平台是一个置顶无边框窗口。
- 快捷键在 **偏好设置 → General** 里改（见下）。组合必须含至少一个修饰键；点 Reset
  链接可恢复默认。

## 命令面板

⌘K / Ctrl+K 打开。它列出应用注册的命令——本模板 15 条，按导航、窗口、通知、应用
分组：侧栏开关、打开偏好设置、最小化/最大化/全屏/关闭、一条测试通知、检查更新。

搜索是对"翻译后的标题与描述"做忽略大小写的子串匹配，不是模糊匹配。当前不可用的命令
（例如侧栏已经隐藏时的"隐藏侧栏"）不会出现在列表里。选中命令会先关闭面板再执行；失败
以 error toast 呈现。

## 偏好设置

⌘, / Ctrl+, 打开，里面有三个面板，顶部面包屑会显示你当前所在面板。

- **General**：Quick Pane 快捷键（录入态：点击后按下组合键，Esc 取消）、开机自启
  开关。这个面板里的两个 example 控件标着"not persisted"，是等你替换的示例。
- **Appearance**：语言（跟随系统、English、中文）与主题（浅色、深色、跟随系统）。
  两者都是立即生效并保存。
- **Advanced**：崩溃上报授权（未配置 Sentry DSN 时该开关禁用，并有一行说明原因），
  以及 API 配置表单。

应用重启后仍然保留的设置只有四项：主题、语言、Quick Pane 快捷键、崩溃上报授权。

## 语言与外观

- 内置语言为英文与中文。选"跟随系统"会读取系统 locale；若不在内置语言里则回退英文。
  切换语言会同时重建原生菜单。
- 主题默认为跟随系统，选中期间持续跟踪系统偏好；改选浅色或深色即停止跟踪。主题会与
  Quick Pane 同步，且两个窗口都在首屏绘制前应用它，所以不会闪白。
- 窗口圆角按平台处理：macOS 交给系统，Windows/Linux 在全屏时自动改为方角。这不是
  一个设置项。
- 从右到左排版的机制是通的（按语言列表决定书写方向），但没有内置 RTL 语言，因此处于
  休眠状态。

## 崩溃上报与恢复

- Rust panic 会在退出前把消息、位置与回溯写入崩溃文件。
- 下次启动时，如果你从未回答过授权问题，会弹出对话框显示崩溃消息与位置，按钮是
  **Send Report** 与 **Don't Send**。不点 Send 就什么都不会发出。两种回答都会被记住：
  已同意的情况下后续报告自动发送，已拒绝的情况下文件静默删除。未配置 Sentry DSN 时
  对话框仍会出现，但发送按钮禁用。
- React 渲染崩溃会显示整屏兜底页，提供 **Reload Application** 与 **Try Again**；
  dev 构建还额外给出可折叠的堆栈详情。
- 崩溃快照保存在应用数据目录下，单文件上限 10 MB，超过 7 天的文件在启动时清理。

## 更新

- 应用启动约 5 秒后自动检查一次更新。这次检查是静默的：不会提示"已是最新"，离线导致
  的检查失败只写日志。
- 主动检查：应用菜单 → Check for Updates，或 ⌘K → "Check for Updates"。只有这条交互
  路径会反馈"已是最新"或错误。
- 发现新版本时以一条常驻 toast 显示版本号与发布说明。**Install update** 之前不会下载，
  应用也不会自行重启——安装完成后提供 **Restart now**。
- **Later** 只是关掉这条提示，并不会退订：下次启动还会问。
- Windows 上安装过程本身就会替换正在运行的程序，因此 "Restart now" 实际上是 macOS 与
  Linux 的路径。
- 更新来自 GitHub Releases，并按签名清单校验。

## 哪些是占位功能

为了不让任何东西被误读成成品特性：

- **偏好设置 → General** 的 example 文本框/开关，以及 **Advanced** 的 example
  开关/下拉：不持久化的示例控件。
- **Advanced → API 配置**：表单会校验地址、API key、超时与重试次数，然后模拟保存并弹
  成功 toast。它没有接到任何请求层，本模板也不会把 API key 发往任何地方。
- **主内容区**：在记录到第一条 Quick Pane 内容之前显示 "Hello World"。
- `greet` 命令服务于偏好设置示例，但没有界面调用它。
- 托盘的"通知"图标状态在代码里存在，但因为没有第二套 badge 图标资源，托盘图标实际上
  永远不会变化。
